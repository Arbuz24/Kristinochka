## Рекомендации по созданию ассетов

1. **Размеры изображений:**
   - Фоны: 1920x1080 или больше (будут масштабироваться)
   - Персонажи: 256x512 пикселей (kristina, you)
   - Машина: 240x400 пикселей (camry)
   - Предметы: 64x64 пикселей (collectibles)
   - Препятствия: 80x80 пикселей (obstacles Главы 1 и 2), 100x100 пикселей (obstacles Глава 3)
   - UI элементы: 300x400 пикселей (для Polaroid)

2. **Стиль:**
   - Используй пиксель-арт или векторную графику
   - Пастельные цвета в соответствии с палитрой игры
   - PNG формат с прозрачностью

3. **Где найти ассеты:**
   - Бесплатные пиксельные спрайты: OpenGameArt.org, Itch.io
   - Создать свои в Aseprite, Piskel или Photoshop
   - Использовать AI генераторы для создания пиксель-арта
